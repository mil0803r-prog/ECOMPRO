# ECOMPRO · Semáforo Dropi GT

Tablero de un solo archivo (`ecompro.html`) que combina Lumy (pedidos de Dropi y landings), Meta Ads, TikTok Ads y DropKiller.

- Secciones: Resumen, Logística (Pedidos, Dinero), Marketing (Landings, Meta, TikTok) e Investigación de mercado (Caza diaria, Mercado, Validador manual).
- Los datos de pedidos, Meta y TikTok son una foto al 7 de octubre de 2026 incrustada en el archivo.
- La Caza diaria, el Validador manual y los parámetros se guardan en la base de datos del artefacto de Claude, no en este archivo.
- Este archivo es la copia de lo publicado como artefacto. Contiene cifras del negocio y IDs de cuentas publicitarias: no lo publiques abiertamente.
